# CSC648 - Software Engineering - Group Term Assignment - Full Stack Website

This project was a term long assignment where I worked in a group of 7, our stack was Django templates, tailwind css and Python, our server was an EC2 amazon webserver. Our assignment was to create an ebay inspired website but only for SFSU students.

## My contribution to the project
- Worked mainly on the profile page, including routing of back-end URLs, profile views, profile template
- Lots of front-end visual changes
- Lots of bug fixes, QA and documentation

## Project Summary / What I learned
This project was incredibly fun to work on, front end is definitely not my forte, but working on this project while collaborating with 7 people was worth the effort.
I learned so much about team collaboration and communication. I cannot stress how much this was an issue in our group, especially when 7 people are working on the same project and need to PR into dev. I also learned a lot about how a larger project should exist and be maintained on github, how QA should be done on a project and how to find security issues.
